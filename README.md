# SoaRBS

A Windows app that sets up and checks your recording.

## Install

1. Open the latest release (**Releases**, on the right of this page) and download
   `SoaRBS_<version>_x64-setup.exe`.
2. Run it. Windows shows a blue "Windows protected your PC" box because the app isn't signed with a
   paid certificate yet. Click **More info**, then **Run anyway**.
3. If Windows asks for administrator permission once, say **Yes**.
4. Open **SoaRBS** from the Start menu. Setup takes about ten minutes.

Already installed? You don't need to do anything. SoaRBS offers new versions itself.
